# Brøkzilla

A small, single-page web app that helps kids practice fraction ("brøk") math — addition, subtraction, multiplication, division, simplifying, common denominators, comparing fractions, and converting mixed numbers to/from improper fractions.

- Danish UI, works on phone and PC.
- No backend, no build step — just static HTML/CSS/JS, styled with [Pico CSS](https://picocss.com/).
- Score is tracked per assignment type, both for the current session and cumulatively (saved in `localStorage`).

## Usage

Open `index.html` in a browser. No install or server required.
